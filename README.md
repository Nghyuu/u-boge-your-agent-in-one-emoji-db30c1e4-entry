One emoji that stands for an AI agent: 🔁

An agent is not a chatbot that answers once — it loops. It perceives, plans,
acts, observes, and repeats until the job is done. The clockwise arrows say
that at a glance: continuous, autonomous work, no caption needed.

`main.ts` writes that single emoji (plus one trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.
